# 專案 Scope

這份文件是 Investment Backtest Lab 的長期目標記憶。當需求變大、文件變多或對話被壓縮時，請優先回到這裡確認專案方向。

## 專案定位

本專案是一個個人投資回測研究實驗室，目標是用可重現、可審計、可擴充的方式研究長期投資策略。它不是實盤交易系統，也不串接券商下單。

第一階段以美股與美股 ETF 做完整驗證，因為美股資料、配息、價格調整與 benchmark 較容易交叉檢查。美股核心完成後，再擴充到台股、台灣 ETF 與台灣基金。

## 長期目標

- 支援美股、美股 ETF、台股、台灣 ETF 與台灣基金回測。
- 產生方便人讀的 Markdown、CSV、HTML 或互動式報表。
- 產生必要圖表：權益曲線、回撤、年度報酬、月報酬、rolling CAGR、曝險、交易、費用與稅。
- 嚴謹驗證資料、現金流、交易成本、股息、稅與匯率換算。
- 支援常用策略，也保留自訂策略擴充點。
- 在研究核心穩定後，提供方便操作的 Streamlit UI。

## Phase 1 範圍：美股嚴謹核心

Phase 1 的目標是把美股單資產與多資產研究流程打穩。

必做：

- 美股與美股 ETF 價格資料。
- 股息資料與明確的現金股息或再投入處理。
- USD 原幣績效與 TWD 換匯後績效。
- Account ledger：交易、費用、稅、股息、現金、部位與每日快照。
- Buy and hold。
- 定期定額 DCA。
- 股息現金入帳與股息再投入。
- 月/季再平衡。
- 基礎成本模型：美股佣金、SEC fee、FINRA TAF、滑價、換匯 spread。
- 基礎稅務模型：美股股息預扣稅率，預設以台灣個人投資者視角。
- L1/L2 驗證：資料品質檢查與 golden case。
- 投資者摘要與 audit appendix 報表。

暫不做：

- 槓桿追繳與強制平倉。
- 台股、台灣基金正式接入。
- 完整個人所得稅、海外所得與最低稅負模擬。
- 正式產品級 Web UI。

## Phase 2 範圍：策略與報表擴充

- 動能輪動。
- 指標降槓桿或升槓桿的研究版策略。
- 更完整的多資產再平衡。
- 參數掃描與敏感度分析。
- 交易明細、成本明細、稅明細與匯率貢獻圖表。
- 使用 `vectorbt`、`bt` 或手算案例交叉驗證。

## Phase 3 範圍：台股與台灣基金

- 台股與台灣 ETF：以 FinMind 為 MVP 主線。
- 台股還原價、除權息與配息處理要在報表標註資料限制。
- 台灣基金：先用 NAV CSV/parquet adapter，之後再評估資料來源。
- 台股成本：手續費、折扣、最低手續費、證交稅。
- 台灣基金成本：申購手續費、經理費、保管費、贖回費與配息假設。

## Phase 4 範圍：UI 與使用體驗

- 第一版 UI 使用 Streamlit。
- 以 config 驅動，不要求使用者改 Python 程式碼。
- UI 至少支援選資產、選策略、調參數、跑回測、看報表、下載結果。
- 若 Streamlit 不能滿足互動需求，再評估正式前後端 Web app。

## 常用策略清單

第一批：

- Buy and hold。
- DCA 定期定額。
- 現金股息。
- 股息再投入。
- 月/季再平衡。
- 均線進出。

第二批：

- 動能輪動。
- 波動度目標。
- 指標降槓桿與升槓桿。
- 自訂訊號策略。
- 自訂資產配置策略。

## 驗收標準

每個主要功能都需要同時滿足：

- 有文件說明用途、限制與操作方式。
- 有可重現的 config 或 script。
- 有單元測試或 golden case。
- 有資料品質檢查或失敗訊息。
- 報表能讓人看懂結果與限制。
- 不破壞既有 quickstart 驗證流程。

## 非目標

- 不做實盤交易。
- 不串接券商。
- 不做高頻或日內交易。
- 不做期貨、選擇權或複雜衍生品。
- 不把免費資料來源視為正式投資決策資料。
- 不在第一階段模擬完整個人稅務。
